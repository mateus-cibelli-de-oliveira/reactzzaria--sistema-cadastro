# Reactzzaria

Aplicação web para pizzarias com frontend moderno, integrado ao banco Firebase. 

Simulação do fluxo básico de um sistema de cadastro para uma pizzaria, permitindo cadastrar dados como tamanhos de pizza, sabores e atualizar o status dos pedidos, com controle de acesso por autenticação.

## Requisitos

[Node.js](https://nodejs.org/) versão `v20.19.0` (ou compatível)

## Instalação

Instale as dependências com:
```bash
yarn install
```
💻 Inicie o projeto localmente com:
```bash
yarn dev
```

## Configurações padrão para variáveis de ambiente

Crie um arquivo `.env.local` na raiz da aplicação, com as seguintes variáveis:

``` 
VITE_API_KEY=
VITE_AUTH_DOMAIN=
VITE_PROJECT_ID=
VITE_STORAGE_BUCKET=
VITE_MESSAGING_SENDER_ID=
VITE_APP_ID=

```
